# ESPHome Configs

> **ESPHome support for IoTextra modules now lives in a dedicated repository:
> [MTH for ESPHome](https://github.com/makethingshappy/MTH-for-ESPHome).**

Go there for:

- the [compatibility matrix](https://github.com/makethingshappy/MTH-for-ESPHome#readme) (module × carrier board),
- up-to-date configs in [`Configs/`](https://github.com/makethingshappy/MTH-for-ESPHome/tree/main/Configs),
- the [setup guide](https://github.com/makethingshappy/MTH-for-ESPHome/blob/main/Documentation/Setup.md).

The `IoTsmart_ESP32-S3/` folder in this directory is kept as an archive and is no longer updated.
Its file names must not change, because firmware built from these configs imports them by URL.
